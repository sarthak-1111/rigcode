Analyze this repository and create (or improve) an AGENTS.md file at the project root. It will be given to coding agents working in this project. Investigate efficiently: README, build and config files (package.json, pyproject.toml, Cargo.toml, go.mod, Makefile, CI workflows...), the top-level layout, and a few representative source and test files. Batch your reads.

AGENTS.md must be concise (aim for 40-120 lines) and contain only what an agent cannot trivially infer:
- **Overview**: what the project is, main languages/frameworks.
- **Commands**: install, build, run, test (including how to run a single test), lint/format. Only commands you verified exist in the project's config.
- **Layout**: the important directories/modules and what lives where.
- **Conventions**: project-specific code style, naming, patterns, error handling and testing practices.
- **Gotchas**: non-obvious setup, environment variables, things that commonly break.

If AGENTS.md or CLAUDE.md already exists, improve it instead of discarding useful content. When done, show a short summary of what you wrote.
